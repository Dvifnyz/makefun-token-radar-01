A token launch radar: 183 pre-token protocols ranked by implied launch value from a sealed DefiLlama snapshot, each with a farm plan — a sortable, filterable board, a detail view per protocol, and the already-trading set shown apart with the market's own values.
## Run it
```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
